ياران درسي مهالوېش — PWA بسته (Progressive Web App)
======================================================

دا ځل ټول فایلونه یوځای، په یوه فولډر کې دي (هیڅ جلا icons فولډر
نشته) — تر څو د لوی/کوچني تورو (case) او د فولډر-ننوتلو ستونزې
مخنیوی وشي.

دا بسته لري:

  index.html
  manifest.json
  service-worker.js
  icon-16.png ... icon-512.png، apple-touch-icon.png، favicon-*.png
  README.txt (همدا فایل)

------------------------------------------------------
مهم: د GitHub ته اپلوډولو طریقه
------------------------------------------------------
ټول پورتني فایلونه باید سیده ستاسو د repository په ریښه (root)
کې واچول شي — نه په کوم بل فولډر (لکه pwa یا icons) دننه. یعنې
کله چې خپل repo ته ګورئ، باید مستقیم دا وګورئ:

  your-repo/
    index.html
    manifest.json
    service-worker.js
    icon-192.png
    ... نور

نومونه باید سمدلاسه لکه دلته لیکل شوي وي — کوچني/لوی توری هم
مهم دي (icon-192.png باید ټول کوچني توري وي، نه Icon-192.png).

------------------------------------------------------
۱. په وړیا ډول انلاین کول (Hosting)
------------------------------------------------------
الف) GitHub Pages
   1. github.com کې یو وړیا حساب جوړ کړئ.
   2. یو نوی Repository جوړ کړئ.
   3. د دې بستې ټول فایلونه (repo root ته، نه کوم فولډر دننه)
      اپلوډ کړئ.
   4. Settings → Pages → Branch: main → Save.
   5. یو څو دقیقو وروسته به یوه پته درکړي.

ب) Netlify (drag & drop) — netlify.com → "Deploy manually" → د
   دې بستې ټول فایلونه (root کچه) درگ اند ډراپ کړئ.

ج) Vercel — ورته طریقه لکه Netlify.

------------------------------------------------------
۲. که مخکې یو ځل ازمویلي وو (اړین ګام)
------------------------------------------------------
که تاسو دمخه پخوانی بسته اپلوډ کړې وه، لومړی زوړ کیش پاک کړئ:

Android/Chrome کې:
  Chrome Settings → Site settings → دا سایټ ومومئ → "Clear &
  reset" → بیا یې له سره خلاص کړئ.

بیا "Add to Home screen" بیا وازمویئ.

------------------------------------------------------
۳. په موبایل کې نصبول (Install)
------------------------------------------------------
1. پورته پته په Chrome (Android) یا Safari (iPhone) کې خلاصه کړئ.
2. Android/Chrome: پورتنۍ ۳ نقطې (⋮) → "Install app" (که یوازې
   "Add to Home screen" ښکاره شي، معنی دا ده چې لاهم یوه ستونزه
   شته — پورته ۱ او ۲ برخې بیا وګورئ).
3. iPhone/Safari: د Share آیکون (⬆️) → "Add to Home Screen".

------------------------------------------------------
۴. آفلاین کارول
------------------------------------------------------
کله چې اپ یو ځل انلاین خلاص شي، service-worker.js به اړین
فایلونه خوندي (Cache) کړي، او له دې وروسته پرته له انټرنېټ هم
به کار کوي. ثبت شوي معلومات (ښوونکي، ټولګي، مضامین، تقسيم اوقات)
په localStorage کې خوندي کیږي — دا د انلاین/آفلاین حالت پورې اړه
نه لري.
